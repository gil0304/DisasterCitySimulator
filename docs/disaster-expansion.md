# 災害・街並み表現の拡張

既存の Vite / React / Three.js 構成と、90棟・3000人の架空都市 Aoba City を使用。
画面下の災害選択から開始し、PAUSE、×1 / ×4 / ×16、RESET で観察する。
詳細カードと最小限の統計表示を維持し、大きな設定画面は追加していない。

## 災害の挙動

| 災害 | 建物と街の変化 | 避難・交通との連動 |
| --- | --- | --- |
| 地震 | 地盤・建築年代・構造・耐震性能から損傷、段階倒壊、粉塵、出火 | 瓦礫による閉塞、揺れの間の車両停止、徒歩迂回 |
| 洪水 | 南側から徐々に浸水、最大約3.8mの基準水深、その後退水 | 水深による通行止め、速度低下、危険な避難所から再避難 |
| 津波 | 洪水より速く広い浸水、最大約7.5mの基準水深、流体荷重を模した追加損傷 | 広範囲の道路・避難所閉鎖、利用可能な経路の再探索 |
| 市街地火災 | 耐火性能が低い3棟から出火、隣棟への延焼、区画ごとの燃焼範囲、焼損 | 火元に近い道路を閉鎖、危険な避難所を候補から除外 |
| 台風 | 時間とともに強くなる風雨、構造の脆弱性に応じた損傷、街路設備の揺れ | 倒壊瓦礫のある道路を回避、災害時の車両減速 |

追加4災害の継続時間・水深・進行方向などは `EnvironmentalDisaster.ts` の
教育用プリセット。水深は建物位置と道路上で同じ関数を参照し、描画にも使う。
終了後も建物被害は残り、RESET で損傷・火・水・道路・避難所・住民・交通を戻す。

## 建物・街・人物

- 無被害 → 軽微 → 半壊・中破 → 大破 → 全壊の5段階。
- 半壊と大破は、外壁の実際の頂点を切り取り、露出した床・柱・割れた部材を追加。
  大破では床の変形と建物の傾斜も残る。全壊まで進まない建物も存在する。
- 全壊は階ごとの時間差で沈み込み、瓦礫が現れる。瞬間消去ではない。
- 木造住宅の屋根・外壁色・年代差、集合住宅の窓とバルコニー・段状上階、
  ガラス張り／段状のオフィス、商店の庇、学校・体育館・病院・工場などを生成。
- 道路グラフから横断歩道・路面標示・信号設備を配置。敷地周辺には駐車区画・塀、
  公園には園路とベンチを追加。建物配置そのものはJSONを使用する。
- 歩行者に頭・胴・手足と歩行周期、身長差、杖・車椅子を追加。インスタンス描画を維持。
- 車両は軽自動車・セダン・バン・トラック・バスの5形状と複数色。
  左側通行・加減速・車間距離・交差点の待機・閉塞道路への進入回避を持つ。

## 計算と描画

`SimulationEngine` が災害・避難・交通を更新し、コンポーネントは状態を描画する。
災害中の交通も固定ステップで進み、フレームレートや待機時間が災害の再現性を変えない。
災害開始時に交通のシード配置を揃える。平常時に見える約280人の歩行者は、
人口を追加しない街の賑わい表現であり、避難人数はJSONの3000人から生成する。

これは特定の実在市街地のGIS再現ではない。地形標高・河川流量・海底地形を使用した
流体解析や、有限要素法による構造解析は行わない。災害の相違と街の変化を観察する
簡易モデルであり、被害区分は実務上の罹災判定を表すものではない。
車は道路グラフを周回し、歩車の衝突判定や車による避難者輸送は扱わない。

## 検証

`npm run hazard:test` は5災害を最後まで実行し、同じシードによるリセット再実行、
一時停止、半壊の残存、損傷の不可逆性、人口・避難所定員の整合、危険な避難所からの
退出、水と道路閉鎖、延焼、全90棟×3段階の形状の有限座標、交通停止を確認する。
既存の `npm run sim:test -- --quiet` は地震の避難経路・人口保存の回帰テスト。
